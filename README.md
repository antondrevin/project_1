# Data Wallet

Анализатор финансовых транзакций: загружает данные из Excel-файла, фильтрует и группирует операции, строит отчёты.

## Возможности

-  Загрузка и парсинг Excel- и JSON-файлов
-  Формирование отчётов:
   - По категориям трат
-  Покрытие тестами (98%)
-  Гибкая структура проекта с использованием `Poetry`, `pytest`, `pandas`

---

## Быстрый старт

1. **Запустите приложение:**
```bash
poetry run python src/main.py
```

2. **Запустите тесты:**
```bash
poetry run pytest --cov=src
```

## Структура проекта
```bash
├── src/
│   ├── main.py               # Точка входа
│   ├── utils.py              # Работа с файлами и форматами
│   ├── services.py           # Поисковые функции
│   ├── reports.py            # Отчеты и декоратор сохранения
│   ├── views.py              # Представления для веб-страниц
│   └── __init__.py           
├── tests/                    # Pytest-тесты
│   ├── test_reports.py
│   ├── test_services.py
│   ├── test_utils.py
│   ├── test_views.py
│   └── ...
├── data/
│   ├──user_settings.json     # Пользовательские настройки
│   └── operations.xlsx       # Excel-файл с операциями
├── logs/
│   ├── activity.log          # Журнал логов
│   └── activity_report.xlsx  # Отчет логов
        
├── .env                      # Переменные окружения
├── .gitignore
├── pyproject.toml
├── README.md                 # Описание проекта
```
## Используемые технологии

- Python 3.13
- pandas
- pytest + pytest-cov
- logging
- re, json, datetime
- poetry
